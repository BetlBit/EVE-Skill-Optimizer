# EVE Skill Optimizer

Локальный оптимизатор прокачки навыков для EVE Online.

Программа помогает составлять очередь обучения, рассчитывать время прокачки и сравнивать варианты ускорения через импланты, ремапы, NES-ускорители и Skill Injectors.

## Возможности

- импорт персонажей из EVEMon файлом .xml.bak;
- анализ текущих навыков и SP;
- создание нескольких целей обучения;
- автоматическое добавление prerequisite-навыков;
- построение оптимальной очереди навыков;
- копирование очереди в формат, который можно вставить обратно в EVE Online;
- расчёт времени обучения;
- учёт атрибутов, имплантов и ремапов;
- учёт временных бустеров;
- расчёт NES Cerebral Accelerators;
- учёт Biology при расчёте длительности ускорителей;
- расчёт Large / Small Skill Injectors;
- комбинирование NES-ускорителей и Skill Injectors;
- расчёт стоимости в ISK;
- получение цен Jita 4-4;
- ручной ввод цены PLEX при необходимости.

## Интерфейс

Основные разделы:

- **Персонаж** — импорт и данные персонажа;
- **Цели обучения** — создание планов прокачки;
- **Итоговая рекомендация** — основной результат;
- **Рекомендованная очередь** — порядок изучения навыков;
- **Ускорение** — ремапы, атрибуты и импланты;
- **Стоимость** — PLEX, NES-ускорители и Skill Injectors;
- **Экспорт** — технические данные и экспорт результатов.
