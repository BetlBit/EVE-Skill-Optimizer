# EVE Skill Optimizer

Локальный оптимизатор прокачки навыков для EVE Online.

Программа помогает составлять очередь обучения, рассчитывать время прокачки и сравнивать варианты ускорения через импланты, ремапы, NES-ускорители и Skill Injectors.

## Возможности

- импорт персонажей из EVEMon;
- анализ текущих навыков и SP;
- несколько целей обучения;
- автоматическое добавление требуемых навыков;
- построение рекомендованной очереди;
- копирование очереди в формат для импорта в EVE Online;
- расчёт времени обучения;
- учёт атрибутов, имплантов, ремапов и временных бустеров;
- расчёт NES Cerebral Accelerators;
- учёт Biology и имплантов на длительность бустеров;
- расчёт Large / Small Skill Injectors;
- комбинирование NES-ускорителей и Skill Injectors;
- расчёт стоимости в ISK;
- цены Jita 4-4;
- ручной ввод цены PLEX.

## Быстрый запуск из исходников

Требуется Python 3.11+.

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
python -m uvicorn app.main:app --port 8010
```

## После запуска перейти по адресу:

http://127.0.0.1:8010

## Сборка Windows

Для полной сборки Windows-версии:

```powershell
.\BUILD_WINDOWS.cmd
```

Готовые файлы появляются в папке `release`.
